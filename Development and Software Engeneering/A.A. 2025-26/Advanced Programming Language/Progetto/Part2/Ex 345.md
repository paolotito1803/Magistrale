## Exercise 3 — Inductive Definitions and Rule Induction

### (a) Derivation trees

Construction of derivation trees for balanced strings.

**Derivation for `(())`:**
$$
\dfrac{
\dfrac{
\dfrac{}{\epsilon \text{ balanced}} ;\text{(bal-empty)}
}{
( \epsilon ) \text{ balanced}
} ;\text{(bal-paren)}
}{
( ( \epsilon ) ) \text{ balanced}
} ;\text{(bal-paren)}
$$
*(Note: $\epsilon$ represents the empty string, so $( \epsilon )$ is equivalent to `()`)*

**Derivation for `()(())`:**
$$
\dfrac{

} ;\text{(bal-paren)}
}{
(()) \text{ balanced}
} ;\text{(bal-paren)}
}{
()(()) \text{ balanced}
} ;\text{(bal-concat)}
$$

### (b) Principle of rule induction

To prove that a property $P(s)$ holds for all strings $s$ such that $s \text{ balanced}$, we must show that:

1. **Base Case:** $P(\epsilon)$ is true.
2. **Inductive Step 1 (Parentheses):** If $P(s)$ is true, then $P((s))$ is true.
3. **Inductive Step 2 (Concatenation):** If $P(s_1)$ and $P(s_2)$ are true, then $P(s_1 s_2)$ is true.

---

### (c) Proof: $len(s) \ge 2 \cdot depth(s)$

We prove this by induction on the rules:

* **Base (bal-empty):**
  $$
  len(\epsilon)=0,\quad depth(\epsilon)=0 \Rightarrow 0 \ge 0
  $$

* **Step (bal-paren):**
  $$
  len(s') \ge 2 \cdot depth(s')
  $$
  $$
  len(s) = len(s') + 2,\quad depth(s) = depth(s') + 1
  $$
  $$
  len(s') + 2 \ge 2(depth(s') + 1)
  $$

* **Step (bal-concat):**
  $$
  len(s_1 s_2) = len(s_1) + len(s_2)
  $$
  $$
  \ge 2,depth(s_1) + 2,depth(s_2)
  $$
  $$
  \ge 2 \cdot \max(depth(s_1), depth(s_2))
  $$

---

### (d) Is `)(` balanced?

**No.** No derivation exists.

*Proof:* Every balanced string must satisfy the property that for every prefix, the number of `(` is $\ge$ the number of `)`.

In the string `)(`:
$$
0 < 1
$$
which violates the condition.

## Exercise 4 — Typing Derivations

### (a) Complete typing derivation

We want to prove that:
$$
\vdash (\lambda f : Nat \to Nat.\ \lambda x : Nat.\ f (f x)) (\lambda y : Nat.\ y + 1) : Nat \to Nat
$$

We define the contexts for brevity:

* $\Gamma_1 = {f: Nat \to Nat, x: Nat}$
* $\Gamma_2 = {y: Nat}$

---

**Left Sub-tree (Function):**
$$
\dfrac{
\dfrac{
\dfrac{}{\Gamma_1 \vdash f : Nat \to Nat} \text{(T-Var)}
\quad
\dfrac{
\dfrac{}{\Gamma_1 \vdash f : Nat \to Nat} \text{(T-Var)}
\quad
\dfrac{}{\Gamma_1 \vdash x : Nat} \text{(T-Var)}
}{
\Gamma_1 \vdash f x : Nat
} \text{(T-App)}
}{
\Gamma_1 \vdash f(f x) : Nat
} \text{(T-App)}
}{
\dfrac{
f: Nat \to Nat \vdash \lambda x : Nat. f(fx) : Nat \to Nat
}{
\vdash \lambda f : Nat \to Nat. \lambda x : Nat. f(fx) : (Nat \to Nat) \to (Nat \to Nat)
} \text{(T-Abs)}
} \text{(T-Abs)}
$$

---

**Right Sub-tree (Argument):**
$$
\dfrac{
\dfrac{}{\Gamma_2 \vdash y : Nat} \text{(T-Var)}
\quad
\dfrac{}{\Gamma_2 \vdash 1 : Nat} \text{(T-Num)}
}{
\dfrac{
\Gamma_2 \vdash y + 1 : Nat
}{
\vdash \lambda y : Nat. y + 1 : Nat \to Nat
} \text{(T-Abs)}
} \text{(T-Add)}
$$

---

**Root (Final Application):**
Joining the two parts with the **(T-App)** rule:
$$
\vdash (\dots)(\dots) : Nat \to Nat
$$

### (b) fix, Reduction and Subject Reduction

Let:
$$
F = \lambda f : Nat \to Nat.\ \lambda n : Nat.\ \text{if } (n = 0)\ \text{then } 0\ \text{else } (f(n+1)) + n
$$

The complete term is:
$$
\text{fix } F
$$

**Reduction (3 steps) for `(fix F) 2`:**
$$
\text{fix } F\ 2 \to (F\ (\text{fix } F))\ 2
$$
$$
\to (\lambda n.\ \text{if } (n=0)\ \text{then } 0\ \text{else } ((\text{fix } F)(n+1)) + n)\ 2
$$
$$
\to \text{if } (2=0)\ \text{then } 0\ \text{else } ((\text{fix } F)(3)) + 2
$$

*Verification:* The term remains of type $Nat$ at every step → **Subject Reduction holds**.

### (c) Ill-typed Term Analysis

Term:
$$
\lambda f : Nat \to Bool.\ \lambda x : Nat.\ (f x) + 1
$$

Error:

* $(f x) : Bool$
* but $+$ requires $Nat$

$$
Bool \neq Nat
$$

So the term is **not typable**.

## Exercise 5 — Type Inference

### (a) Trace for `\f. \g. \x. if (f x) then (g x) else x`

1. **Fresh variables:** $f: \alpha,\ g: \beta,\ x: \gamma$
2. **Constraints:**

   * $\alpha = \gamma \to \delta$
   * $\delta = Bool$
   * $\beta = \gamma \to \epsilon$
   * $\epsilon = \gamma$
3. **Unification:**

   * $\alpha = \gamma \to Bool$
   * $\beta = \gamma \to \gamma$
4. **Principal Type:**
   $$
   (\gamma \to Bool) \to (\gamma \to \gamma) \to \gamma \to \gamma
   $$

---

### (b) Contradiction in `\f. f (f 1) (f true)`

* From $(f 1)$ → $f : Nat \to \dots$
* From $(f\ true)$ → $f : Bool \to \dots$

$$
Nat \neq Bool
$$

**Conclusion:** Unification fails → term is **not typable**.
