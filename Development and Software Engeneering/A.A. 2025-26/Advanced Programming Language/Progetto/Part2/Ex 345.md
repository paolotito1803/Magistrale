## Esercizio 3 — Inductive Definitions and Rule Induction

### (a) Derivation trees
Costruzione degli alberi di derivazione per le stringhe bilanciate.

**Derivazione per `(())`:**
$$
\frac{
    \frac{
        \frac{}{\epsilon \text{ balanced}} \text{(bal-empty)}
    }{( \epsilon ) \text{ balanced}} \text{(bal-paren)}
}{( ( \epsilon ) ) \text{ balanced}} \text{(bal-paren)}
$$
*(Nota: $\epsilon$ rappresenta la stringa vuota, quindi $( \epsilon )$ equivale a `()`)*

**Derivazione per `()(())`:**
$$
\frac{
    \frac{
        \frac{}{\epsilon \text{ balanced}} \text{(bal-empty)}
    }{() \text{ balanced}} \text{(bal-paren)}
    \quad
    \frac{
        \frac{
            \frac{}{\epsilon \text{ balanced}} \text{(bal-empty)}
        }{() \text{ balanced}} \text{(bal-paren)}
    }{(()) \text{ balanced}} \text{(bal-paren)}
}{()(()) \text{ balanced}} \text{(bal-concat)}
$$

### (b) Principle of rule induction
Per dimostrare che una proprietà $P(s)$ vale per tutte le stringhe $s$ tali che $s \text{ balanced}$, dobbiamo mostrare che:
1. **Caso Base:** $P(\epsilon)$ è vero.
2. **Passo Induttivo 1 (Parentesi):** Se $P(s)$ è vero, allora $P((s))$ è vero.
3. **Passo Induttivo 2 (Concatenazione):** Se $P(s_1)$ e $P(s_2)$ sono veri, allora $P(s_1 s_2)$ è vero.

### (c) Proof: $len(s) \ge 2 \cdot depth(s)$
Dimostriamo per induzione sulle regole:
- **Base (bal-empty):** $len(\epsilon)=0, depth(\epsilon)=0$. $0 \ge 2(0)$ (Vero).
- **Passo (bal-paren):** Sia $s = (s')$. Per IP: $len(s') \ge 2 \cdot depth(s')$.
  $len(s) = len(s') + 2$.
  $depth(s) = depth(s') + 1$.
  Sostituendo: $len(s') + 2 \ge 2(depth(s') + 1) \Rightarrow len(s') + 2 \ge 2 \cdot depth(s') + 2$. (Vero per IP).
- **Passo (bal-concat):** Sia $s = s_1 s_2$. Per IP: $len(s_1) \ge 2d(s_1)$ e $len(s_2) \ge 2d(s_2)$.
  $len(s_1 s_2) = len(s_1) + len(s_2) \ge 2d(s_1) + 2d(s_2) \ge 2 \cdot \max(d(s_1), d(s_2)) = 2 \cdot depth(s_1 s_2)$. (Vero).

### (d) Is `)(` balanced?
**No.** Non esiste derivazione. 
*Prova:* Ogni stringa bilanciata deve soddisfare la proprietà che per ogni prefisso, il numero di `(` è $\ge$ al numero di `)`. Nella stringa `)(`, il primo prefisso è `)` dove $0 < 1$, violando la condizione necessaria per essere bilanciata secondo le regole date.

## Exercise 4 — Typing Derivations

### (a) Complete typing derivation
Vogliamo dimostrare che:
$\vdash (\lambda f : Nat \to Nat. \lambda x : Nat. f (f x)) (\lambda y : Nat. y + 1) : Nat \to Nat$

Definiamo i contesti per brevità:
- $\Gamma_1 = \{f: Nat \to Nat, x: Nat\}$
- $\Gamma_2 = \{y: Nat\}$

**Sotto-albero Sinistro (Funzione):**
$$
\frac{
    \frac{
        \frac{}{\Gamma_1 \vdash f : Nat \to Nat} \text{(T-Var)} \quad \frac{\frac{}{\Gamma_1 \vdash f : Nat \to Nat} \text{(T-Var)} \quad \frac{}{\Gamma_1 \vdash x : Nat} \text{(T-Var)}}{\Gamma_1 \vdash f x : Nat} \text{(T-App)}
    }{\Gamma_1 \vdash f(f x) : Nat} \text{(T-App)}
}{
    \frac{\{f: Nat \to Nat\} \vdash \lambda x : Nat. f(fx) : Nat \to Nat}{\vdash \lambda f : Nat \to Nat. \lambda x : Nat. f(fx) : (Nat \to Nat) \to (Nat \to Nat)} \text{(T-Abs)}
} \text{(T-Abs)}
$$

**Sotto-albero Destro (Argomento):**
$$
\frac{
    \frac{}{\Gamma_2 \vdash y : Nat} \text{(T-Var)} \quad \frac{}{\Gamma_2 \vdash 1 : Nat} \text{(T-Num)}
}{
    \frac{\Gamma_2 \vdash y + 1 : Nat}{\vdash \lambda y : Nat. y + 1 : Nat \to Nat} \text{(T-Abs)}
} \text{(T-Add)}
$$

**Radice (Applicazione Finale):**
Unendo i due pezzi con la regola **(T-App)**, il tipo dell'argomento $(Nat \to Nat)$ combacia con il dominio della funzione, producendo il tipo finale:
$$\vdash (\dots) (\dots) : Nat \to Nat$$

### (b) fix, Reduction and Subject Reduction
Sia $F = \lambda f : Nat \to Nat. \lambda n : Nat. \text{if } (n = 0) \text{ then } 0 \text{ else } (f (n + 1)) + n$.
Il termine completo è $\text{fix}@ (Nat \to Nat) \ F$.

**Derivazione di fix:**
1. Assumiamo $f: Nat \to Nat$ e $n: Nat$.
2. Il test $(n=0)$ ha tipo $Bool$ (**T-Eq**).
3. Il ramo `then` (0) ha tipo $Nat$.
4. Il ramo `else` ha tipo $Nat$ perché è una somma (**T-Add**) tra $(f(n+1))$, che è $Nat$, e $n$, che è $Nat$.
5. Per **T-If**, il corpo ha tipo $Nat$. Per **T-Abs**, $F$ ha tipo $(Nat \to Nat) \to (Nat \to Nat)$.
6. Per **T-Fix**, $\text{fix } F$ ha tipo $Nat \to Nat$.

**Riduzione (3 step) per `(fix F) 2`:**
1. $\text{fix } F \ 2 \longrightarrow (F \ (\text{fix } F)) \ 2$
   *Tipo: Nat* (Applicazione di $F$ a due argomenti).
2. $\longrightarrow (\lambda n. \text{if } (n=0) \text{ then } 0 \text{ else } ((\text{fix } F) (n+1)) + n) \ 2$
   *Tipo: Nat* (Sostituzione di $f$ con $\text{fix } F$).
3. $\longrightarrow \text{if } (2=0) \text{ then } 0 \text{ else } ((\text{fix } F) (2+1)) + 2$
   *Tipo: Nat* (Sostituzione di $n$ con 2).

*Verifica:* Ad ogni passaggio, il termine rimane ben tipizzato come $Nat$, confermando il teorema di **Subject Reduction**.

### (c) Ill-typed Term Analysis
Termine: $\lambda f : Nat \to Bool. \lambda x : Nat. (f x) + 1$

L'algoritmo di type-checking fallisce applicando la regola **T-Add** al sotto-termine $(f x) + 1$:
1. La regola **T-Add** richiede: $\Gamma \vdash M : Nat$ e $\Gamma \vdash N : Nat$.
2. Qui $N$ è $1$ (tipo $Nat$), ok.
3. Ma $M$ è $(f x)$. Poiché $f : Nat \to Bool$ e $x : Nat$, la regola **T-App** assegna a $(f x)$ il tipo **Bool**.
4. **Mismatch:** L'operatore `+` non è definito per il tipo $Bool$. L'algoritmo si ferma perché non può unificare $Bool$ con $Nat$.

## Esercizio 5 — Type Inference

### (a) Trace for `\f. \g. \x. if (f x) then (g x) else x`
1. **Variabili fresche:** $f: \alpha, g: \beta, x: \gamma$.
2. **Vincoli generati:**
   - Da `(f x)`: $\alpha = \gamma \to \delta$.
   - Da `if (f x)`: $\delta = Bool$.
   - Da `(g x)`: $\beta = \gamma \to \epsilon$.
   - Da `then/else`: $\epsilon = \gamma$ (i rami devono coincidere).
3. **Unificazione:**
   - $\alpha = \gamma \to Bool$
   - $\beta = \gamma \to \gamma$
4. **Principal Type:** $(\gamma \to Bool) \to (\gamma \to \gamma) \to \gamma \to \gamma$.

### (b) Contradiction in `\f. f (f 1) (f true)`
- Da `(f 1)` ricaviamo che $f$ deve accettare $Nat$ ($\text{tipo di } f = Nat \to \dots$).
- Da `(f true)` ricaviamo che $f$ deve accettare $Bool$ ($\text{tipo di } f = Bool \to \dots$).
- **Contraddizione:** Un'unica variabile $f$ non può avere due tipi diversi ($Nat$ e $Bool$) per il suo argomento nel sistema di tipi semplici. L'unificazione fallisce perché $Nat \neq Bool$.
